# VBA TOURISM

A modern, responsive tourism website showcasing beautiful destinations across India.

## Features

- 🗺️ Interactive navigation with state-wise destinations
- 🔍 Smart search functionality to find cities
- 🖼️ Beautiful image galleries for each destination
- 📱 Fully responsive design
- 🎨 Modern UI with smooth animations
- 🏛️ Detailed information about tourist attractions

## States Covered

- **Telangana**: Hyderabad, Warangal, Nizamabad, Karimnagar, Alampur
- **Andhra Pradesh**: Visakhapatnam, Vijayawada, Tirupati, Guntur
- **Tamil Nadu**: Chennai, Coimbatore, Madurai, Ooty
- **Karnataka**: Bangalore, Mysore, Hampi, Coorg
- **Kerala**: Kochi, Munnar, Alleppey, Kovalam
- **Arunachal Pradesh**: Tawang, Ziro, Bomdila, Itanagar

## Technologies Used

- React.js
- React Router
- Vite
- CSS3 with modern animations
- Responsive design

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
